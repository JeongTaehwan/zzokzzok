# 쪽쪽 개인정보 처리방침

**시행일: 2026-09-24**

쪽쪽(이하 "앱")은 아기 수유 시간을 기록하고 다음 수유 시간을 알려주는 앱입니다.
앱은 이용자의 개인정보를 **수집하지 않으며, 외부 서버로 전송하지 않습니다.**

## 1. 수집하는 정보

앱은 어떤 개인정보도 수집·저장·전송하지 않습니다. 이용자가 앱에 입력하는 다음 정보는 **이용자의 기기 안에만** 저장됩니다.

- 아기 이름 (알림 문구에 사용)
- 수유 시작/종료 시각, 수유 종류
- 알람 간격 등 설정값

## 2. 정보의 저장 위치와 삭제

- 모든 데이터는 기기 내부 저장소(Android: 앱 전용 저장 공간 / iOS: 앱 샌드박스)에만 저장됩니다.
- 앱 내 **설정 → 모든 기록 삭제** 로 언제든 삭제할 수 있으며, 앱을 삭제하면 모든 데이터가 함께 삭제됩니다.
- 기기 백업 설정(Google 백업, iCloud 백업)에 따라 이용자의 계정으로 백업될 수 있으며, 이는 각 플랫폼의 정책을 따릅니다.

## 3. 권한

| 권한 | 용도 |
|---|---|
| 알림 | 다음 수유 시간 알림 표시 |
| 정확한 알람 (Android) | 설정한 시각에 정확히 알림을 울리기 위해 사용 |
| 진동 | 알람 시 진동 |
| 재부팅 완료 수신 (Android) | 재부팅 후 예약된 알림 복원 |

## 4. 제3자 제공 및 분석 도구

앱은 광고, 분석(애널리틱스), 크래시 리포트 등 어떠한 제3자 SDK도 사용하지 않으며, 인터넷 연결 없이 동작합니다.

## 5. 아동의 개인정보

앱은 양육자를 위한 도구이며, 아동으로부터 직접 정보를 수집하지 않습니다.

## 6. 방침 변경

방침이 변경되면 이 문서와 앱 스토어 페이지를 통해 공지합니다.
